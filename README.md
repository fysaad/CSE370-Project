# 🌾 Krishi Direct

**Krishi Direct** is a web-based agricultural marketplace designed to connect farmers directly with buyers, cutting out middleman costs and ensuring fair prices for farm produce.

🔗 **Live Demo:** [krishidirect.onrender.com](https://krishidirect.onrender.com/)

---

## 📌 Features
- **Direct Selling:** Farmers can list their crops and agricultural products easily.
- **Buyer Browsing:** Customers can search and browse fresh farm produce.
- **User Accounts:** Secure registration and login for buyers and sellers.
- **Order Management:** Database-driven order tracking and management.

---

## 🛠️ Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS
- **Deployment:** Render
